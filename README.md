# Modern Login UI

A modern and minimalist login and registration interface built with HTML, CSS and JavaScript, featuring a dark glassmorphism design.

## 🔗 Live Demo

Check out the project online:

[**Modern Login UI – View Project**](https://tenorioux.github.io/Modern-Login-UI/)

## 📌 About the Project

Modern Login UI is a front-end project focused on creating a clean, elegant and modern registration experience.

The interface combines a dark aesthetic, glassmorphism effects, minimalist input fields and social media buttons.

## ✨ Features

- Modern and minimalist design
- Dark glassmorphism interface
- Transparent input fields
- Custom input focus effects
- Green interactive buttons
- Social media icon buttons
- Responsive layout (in development)

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling, Flexbox and visual effects
- **JavaScript** – Project scripting
